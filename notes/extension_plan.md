| 缺口 | 证据 |

## 1. 查新结论（2026-10-26）

- **FairlyUncertain (arXiv:2410.02005)**：预测不确定性 × 公平性的基准，**不是**公平性度量的统计推断 → 不撞车。
- **E-FairDrift (ICML 2026)**：任意时间有效的交叉公平性漂移检验 → **anytime-valid 路线已被占**，本工作不作为主贡献（可作为展望）。
- **Error, Variance, Fairness, and the Curse on Minorities**：少数子群公平性估计的方差问题 → 与 G1 相关，需引用并明确差异（他们关注子群估计方差；我们关注训练/评估/约束集三源分解与联合区间）。
- 未检索到"在线训练公平性的三源不确定性分解 + 联合置信区间 + 样本量规划"的直接工作 → 创新点可立。

## 2. 拟定贡献

**题目（暂定）**：*Total Uncertainty Quantification for Fairness of Online-Trained
Classifiers: Separating Training, Evaluation and Constraint-Set Noise*

1. **三源分解定理**。设 φ 为 DI 或 DM，θ* 为给定约束集 D' 下的总体最优解，θ̄_T 为在线平均迭代，
   φ̂_m 为在 |D̃|=m 的留出集上的估计。则
   $$\hat\phi_m(\bar\theta_T)-\phi(\theta^*) =
     \underbrace{[\hat\phi_m(\bar\theta_T)-\hat\phi_m(\theta^*)]}_{\text{训练}}+
     \underbrace{[\hat\phi_m(\theta^*)-\phi(\theta^*)]}_{\text{评估}}.$$
   两项渐近独立；方差 $\sigma_\Delta^2/T + v^2/m$。论文的 bootstrap 只估计第一项。
   若再对 D' 抽样，θ* 变为 θ*(D')，增加第三项（约束集/部署设计噪声），给出其 bootstrap 方差。

2. **多源 bootstrap 联合区间**（计算几乎免费）：
   - 训练源：复用论文 Algorithm 2 的 B 条乘子轨迹；
   - 评估源：对 D̃ 做多重抽样权重（对每个 b 独立重抽），重新评估预测；
   - 约束集源：外层 R 次重抽 D'（需重训练，R 小，如 20–50），给出 θ* 变异。
   合并得到 β 分位数区间；对 φ=|Δ| 的非光滑性用折叠正态/在 Δ 的区间上取绝对值两种构造，并给
   finite-sample 修正（子群小样本用 Wilson 型校正）。

3. **样本量规划**。给定目标半宽 w 与水平 α，
   $$z_{1-\alpha/2}\sqrt{\sigma_\Delta^2/T + v^2/m}\le w,$$
   结合单步训练/标注成本给出 (T, m) 的最优配比；证明现行做法（m=100–1000 ≪ T）在多数情形下
   评估噪声主导，浪费训练算力。给出"最小可辨不公平度"公式。

4. **实验**：合成（论文 DGP + 良态 DGP）× Adult / ACSIncome / COMPAS；方法对比：
   论文 CI（固定时间）、我们的联合 CI、离线 bootstrap、Delta 方法、批量均值估计；
   指标：对留出/总体两目标的覆盖率、区间宽度、MIS、样本量-成本曲线；
   再加 κ、T、m 的敏感性分析。

## 3. 与论文的关系

- 论文是"训练噪声"的渐近理论；我们给出**部署视角的总不确定性**，并指出其 CI 的适用范围。
- 复现报告作为论文的第 2 节/附录（"背景与复现发现"），诚实呈现三处缺口，作为动机。
- 不主张论文错误，而主张其推断目标是"留出集上的公平性"，与部署关心的"总体公平性"不同。
